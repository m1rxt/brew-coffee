# Brew Coffee — Кофейня и каталог

## Возможности
- Каталог кофе и выпечки с поиском, фильтрацией по категориям и сортировкой.
- Добавление новых товаров прямо на сайте (кнопка **+ Добавить товар** в шапке).
- Корзина и оформление заказов с сохранением в PostgreSQL.
- Просмотр списка оформленных заказов в модальном окне.

## Запуск проекта
1. В pgAdmin 4 создайте базу `brew_coffee` (если ещё не создана) и выполните `database.sql`.
2. Укажите ваш пароль `postgres` в файле `.env` (`DB_PASSWORD=`).
3. Выполните `npm install` и `npm start`.
4. Откройте `http://localhost:3000`.
